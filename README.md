# 🎯 AIM LAB PRO - 3D FPS Precision Aim Trainer

Ultra-responsive, WebGL-based 3D FPS Aim Training Platform built with React, Three.js (@react-three/fiber), TypeScript, Tailwind CSS, Procedural Web Audio API, and 50+ training scenarios.

## 🚀 Features
- **Raw Input 3D Engine**: Zero latency Pointer Lock camera controller with 1:1 Valorant, CS2, Apex Legends, Overwatch 2 sensitivity profiles.
- **50+ Scenarios**:
  - Clicking / Flicking (Gridshot Ultimate, Reflex Shot, Sixshot...)
  - Continuous Tracking (Smoothness 360, Thin Shaft, Reactive Tracking...)
  - Target Switching (PatTargetSwitch, 360 Speed Switch...)
  - AI Strafing Bots (ADAD Humanoids, Jumping Bots, 360 Survival...)
- **Custom Scenario Studio**: Create, test, and save custom aim scenarios with configurable target speeds, radii, and health.
- **Web Audio API Sound Engine**: Procedural crystal hit chimes, headshots, combo pitch escalations, and gunshots.
- **Full Analytics & Radar**: Match telemetry, reaction times, KPS, accuracy curves, and personal best tracking.
- **Crosshair Studio**: Fully customizable reticles with live preview and firing spread bloom.

## 📦 Deployment (Vercel)
This project is configured out-of-the-box for Vercel deployment:
- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
